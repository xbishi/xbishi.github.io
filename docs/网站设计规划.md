# 网站设计规划 — bs-portfolio

> 2026-11-19 立项设计。本文档是唯一设计基准，改动需记决策日志。

## 1. 定位

**门面 + 控制台二合一**：
- 对外（作品集）：给客户/合作方/潜在雇主看——突出项目亮点、成果截图、技术栈，第一印象要体面
- 对内（导航台）：负责人自己每天用的入口——聚合所有项目的在线演示/仓库/文档链接和状态

首期以对外展示为主（负责人未拍板时的默认方向，理由：自用导航只需要书签文件夹就能凑合，对外展示做不了替代品；且两者数据同源，后加导航视图成本低）。

## 2. 信息架构

```
/                       首页
 ├─ Hero                名字 + 一句话定位 + 关键数字（N 个项目 / M 个可在线体验）
 ├─ 精选项目            3~4 张大卡片（featured: true 的项目）
 ├─ 全部项目            卡片网格，支持筛选：类型 / 状态 / 年份
 └─ 页脚                联系方式 + GitHub 链接

/projects/[slug]        项目详情页
 ├─ 封面大图或视频
 ├─ 一句话定位 + 状态徽章 + 年份
 ├─ 背景与问题（为什么做）
 ├─ 做了什么（亮点 3 条，成就导向）
 ├─ 截图画廊（2~4 张）
 ├─ 技术栈标签
 └─ 链接区：在线演示 / 源码 / 文档 / 相关文章

/about                  关于页（背景、技能矩阵、合作方式）
```

## 3. 数据驱动（核心设计决策）

**一个项目 = 一个 Markdown 文件**，放 `src/content/projects/`：

```yaml
# src/content/projects/mesh2motion.md 的 frontmatter
title: Mesh2Motion 动画管线
slug: mesh2motion
summary: 一句话介绍（卡片上显示）
status: active        # active 进行中 | done 已完成 | archived 已归档
type: pipeline        # tool 工具 | game 游戏 | film 影视 | pipeline AI管线 | site 网站
year: 2026
cover: /covers/mesh2motion.webp
tech: [Blender, Python, ComfyUI]
links:
  demo: https://...
  repo: https://github.com/...
  docs: ...
featured: true        # 是否上首页精选
order: 1              # 排序权重
---
正文 = 项目详情页内容（背景 / 亮点 / 截图画廊用组件标记）
```

**与工作空间治理对齐**（长期愿景）：
- `H:/BS一人公司/项目/` 下每个项目的 `PROJECT.md` 本身就含定位信息，未来可写脚本自动同步到网站数据
- 工作空间项目移入归档 → 网站数据 status 同步改 archived（首期手动，M3 后考虑脚本）

## 4. 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 框架 | **Astro 5.x** | 内容站最优解：默认零 JS 输出（页面极快）、content collections 原生支持「一项目一 md」、构建快 |
| 样式 | **Tailwind CSS 4** | 快速迭代卡片/响应式布局，不手写 CSS 体系 |
| 交互 | 原生 JS islands（Astro 默认模式） | 只有筛选/主题切换需要 JS，其余纯静态 |
| 图片 | Astro 内置 `<Image>` 自动转 webp + 懒加载 | 截图多是 PNG 大图，必须优化 |
| 部署 | **GitHub Pages + GitHub Actions** | 免费零运维，push 即部署；域名后绑 |
| 包管理 | pnpm（Node 24 已在 `_tools/`） | 快、省磁盘 |

**替代路径**（若负责人推翻）：要互动性/以后加后端 → Next.js；要极简 → 纯 HTML 单页。

## 5. 视觉方向

- **深色主题为主，可切浅色**（个人技术站主流，截图观感更好）
- 卡片网格：封面图占卡片 60% 高度，信息区紧凑（标题/一句话/状态徽章/技术标签）
- 状态徽章语义：`active` 绿点、`done` 灰对勾、`archived` 暗色降透明度
- 中文字体走系统栈（`system-ui`），不加载 webfont（首屏速度优先）
- 首页一屏内说清「这是谁、做过什么、怎么联系」

## 6. 里程碑

| 里程碑 | 内容 | 验收仪式 |
|---|---|---|
| **M1 骨架上线** | Astro 项目搭建、首页 + 详情页模板、≥3 个项目数据、GitHub Pages 部署流水线 | 手机打开公网地址，能浏览 3 个项目 |
| **M2 数据补齐** | 全部项目（≥8 个）录入、筛选功能、关于页 | 负责人试用并认可项目清单无遗漏 |
| **M3 打磨** | 深浅色切换、SEO/OG 卡片、Lighthouse 优化、访问统计（可选 umami 自托管） | Lighthouse ≥90 + 负责人验收观感 |

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 国内访问 GitHub Pages 慢 | 首期接受；真卡再决策日志立项换 Vercel 或 CDN 前置 |
| 项目截图素材缺失 | 详情页支持无图模式（纯排版），后续补图 |
| 项目多了难维护 | 数据驱动已把成本降到「填一个 md」；再加脚本自动同步 |
| 域名/备案问题 | 首期用 `xxx.github.io` 免费域名，不碰备案 |
