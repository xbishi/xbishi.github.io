# 留言审核流程 — 从访客留言到弹幕

> 链路：访客留言 → 服务器待审核队列 → **定期拉取到本地** → 审核 → 写入弹幕池 → 重新构建上线

## 1. 服务器侧（部署 feedback-server 后自动）

访客在项目详情页提交留言 → `POST /api/feedback` → 落盘到服务器
`/var/lib/bs-portfolio-feedback/pending/<项目>-<时间戳>.json`

## 2. 定期拉取到本地（AI 执行，或手动）

```bash
# 拉取全部待审核留言到本地审核目录
scp -P <端口> <用户>@<服务器>:/var/lib/bs-portfolio-feedback/pending/*.json \
  "H:/BS一人公司/项目/bs-portfolio/协作/留言审核/pending/"

# 拉完可清空服务器 pending（可选）
ssh -p <端口> <用户>@<服务器> "rm /var/lib/bs-portfolio-feedback/pending/*.json"
```

## 3. 审核（人工过目 + AI 整理）

每条留言一个 JSON（project/nick/text/at/ip）。审核原则：
- **收录**：具体建议、真实使用反馈、友好打气
- **丢弃**：广告、灌水、人身攻击、内容与项目无关
- 敏感词/链接默认不收录

## 4. 写入弹幕池

审核通过的留言追加到 [src/data/feedback.json](../src/data/feedback.json) 对应项目数组：

```json
{ "nick": "昵称", "text": "留言内容", "from": "visitor" }
```

保存后重新构建部署（`pnpm build` + 部署 dist），弹幕即带上新留言。

## 5. 自动化（可选）

服务器上线后可让 AI 建立定时任务（如每周一上午）自动执行步骤 2-4 并汇报
「本周新增留言 N 条，收录 M 条」。

## 安全备注

- feedback-server 只监听 127.0.0.1，外网经 nginx 反代 `/api/`
- 字段长度硬校验（昵称 24 / 内容 200）、字符过滤、同 IP 每分钟 5 条限速
- 弹幕池是白名单模式：只有人工审核过的内容才进构建
